# WeLovePDF — Chrome & Edge Extension (Manifest V3)

This extension provides a 1-click browser launcher for **WeLovePDF.best** — the 100% private in-browser PDF toolkit powered by WebAssembly.

---

## 🚀 How to Test in Chrome / Edge Right Now (Load Unpacked)

1. Open your browser and go to:
   - **Google Chrome:** `chrome://extensions/`
   - **Microsoft Edge:** `edge://extensions/`
   - **Brave:** `brave://extensions/`
2. Toggle on **"Developer mode"** in the top-right corner.
3. Click the **"Load unpacked"** button.
4. Select this directory: `e:\WeLovePDF\extension`.
5. The **WeLovePDF** icon will appear in your browser extension toolbar!
6. Click it to open the quick launcher.
